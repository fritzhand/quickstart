Step 3 · Just enough Git

Commit as yourself

Every commit records an author. Give the agent your name and your GitHub noreply email so the work is credited to you, not to Claude.

Time: 5 min

In the Claude app, Claude's cloud machine commits as Claude <noreply@anthropic.com> unless you say otherwise. Those commits aren't credited to you and don't show on your GitHub profile. One sentence fixes it.

Get your noreply email

It looks like ID+your-username@users.noreply.github.com. You copied it in Create your GitHub account. It's on GitHub under Settings → Emails. It credits you without putting your real email in your site's public history.

Tell the agent

App path

Say this
In your-username/your-repo, set git user.name to "Your Name" and user.email to "your-noreply-email", and commit as me from now on. Add this rule to a CLAUDE.md file at the root of that repo (create it if needed) so every session follows it: Commit as Your Name <your-noreply-email>. Before your first commit in each session, set git user.name and user.email to these in this repo. Then commit and push to main.

Each session starts on a fresh machine, so the setting is gone next time. Claude reads CLAUDE.md at the start of every session, so the rule brings it back.

VS Code path

The agent commits with your computer's git identity. Set it once, and it applies to every repo on this computer:

Say this
Set my global git name to "Your Name" and email to "your-noreply-email".

The name is what your commits show, usually your full name. It doesn't have to match your GitHub username.

Check it worked

Open https://github.com/your-username/your-repo/commits/main. Your newest commit shows your name and profile picture as the author. Claude's picture may appear beside yours as a co-author, because Claude adds a Co-Authored-By line to the commit message. That's expected. Commits on main can take up to 24 hours to appear on your profile's contribution graph. Commits in a fork don't count there; see Clone, fork or copy.

If it goes wrong

My older commits still say Claude

The setting changes only new commits. Leave the old ones as they are.

My name shows on the commit, but not on my profile

Check three things: the email is your noreply address exactly, the repo isn't a fork, and the commit is on main. Then allow up to 24 hours.

What the agent runs for you 
# App path: this repo only (the machine is fresh each session)
git config user.name "Your Name"
git config user.email "your-noreply-email"

# VS Code path: every repo on your computer
git config --global user.name "Your Name"
git config --global user.email "your-noreply-email"

# Who wrote the last commit?
git log -1 --format="%an <%ae>"

Your details

Fill these in once. Every prompt in the guide updates to use them, so you can copy and paste without editing.

The name in your GitHub profile address, github.com/your-username.

What you’ll call the repo for your site, in lowercase with hyphens, such as history-of-st-pete. It becomes part of your site’s address. You can change it here later.

Shown as the author of your commits.

On GitHub, open Settings → Emails and check Keep my email addresses private. GitHub then shows your address ending in @users.noreply.github.com.

That doesn’t look like a GitHub noreply address. It should end in @users.noreply.github.com.
