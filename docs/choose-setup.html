Step 2 · Set up your agent

App or VS Code?

You can run the agent in two places. The app path runs in a browser with nothing to install, or in the Claude app on your phone. The VS Code path runs on your computer. Pick one now; you can add the other later.

Time: 2 min

The two paths

The app pathThe VS Code path
What it isClaude Code in the Claude appVS Code with the Claude Code extension or the Codex extension
Where the agent worksOn a fresh copy of your repo in the cloudIn a folder on your computer
What to installNothing in a browser. On a phone, the Claude app.VS Code and the extension. The agent then installs Git and Node.js for you; the GitHub CLI is optional. On Windows, one setting to allow scripts.
DevicesA phone or tablet, any web browser, or the Claude desktop appA Mac or Windows computer
What you do by handSign in, connect GitHub and install the Claude GitHub App, once. Turn on GitHub Pages in your repo's settings on github.com.Install VS Code and the extension, sign in, and approve the agent's requests. Turn on GitHub Pages on github.com, or let the GitHub CLI do it.
CostA paid Claude plan: Pro, Max, Team or an Enterprise seat that includes Claude CodeFor Claude Code, a paid Claude plan. For Codex, ChatGPT Plus or higher.
Best forBeginners, phones, and the fastest startSeeing and opening your files on your computer, or using Codex

Everything else, on both paths, you type or dictate to the agent. GitHub is free on both paths. The free Claude plan doesn't include Claude Code.

Which one?

  • New to this, or on a phone? Start with the app path. It's the fastest way to a live site.
  • Want to see the files on your computer? Pick the VS Code path. Codex users take this path too.
  • Can't decide? You don't have to. Both paths work on the same repo, because the real copy lives on GitHub. Push from one, then pull in the other.
