Step 2 · Set up your agent

Git, Node & GitHub CLI

Three free tools let the agent save versions of your site, build it, and handle GitHub for you. You ask, and the agent installs them.

Time: 15 minVS Code path

What each tool is for

ToolWhat it does for youDo you need it?
GitSaves versions of your files and sends them to GitHub.Yes.
Node.jsRuns the build script some starters use. The Startup Schemes Playbook builds with node build.mjs. The Tampa starter needs no build.Install it anyway. It's quick.
GitHub CLI (gh)Lets the agent do GitHub chores for you: create and fork repos, and turn on GitHub Pages.Optional, but it's what saves you the clicking on GitHub.

Have the agent install them

  1. Ask for the installs

    Say this
    Install whatever is missing from git, node and the GitHub CLI (gh). Use the right method for this computer: winget on Windows; on a Mac, Homebrew if I have it, or xcode-select --install for git. If a step needs my password or a click in an installer window, stop and tell me exactly what to do. Then run git config --global init.defaultBranch main so my new repos start on a branch called main.

  2. Approve and click through

    The agent may ask before each install. Read the command, then allow it. Windows may ask whether to allow changes to your device, and a Mac may ask for your password. Both are normal for an install.

    If an installer window opens, keep the defaults. In the Git for Windows installer, on the page about the name of the initial branch, choose Override the default branch name for new repositories and type main.

  3. Restart VS Code

    Close every VS Code window, then open VS Code again. It only finds new tools when it starts.

  4. Sign the GitHub CLI in to your account

    Do this yourself

    This sign-in asks you questions and opens your browser, so you answer it, not the agent.

    Open the terminal with View → Terminal. Type this and press Enter:

    Terminal
    gh auth login

    Answer with the arrow keys and Enter. Choose GitHub.com, then HTTPS. Say yes when it offers to use your GitHub login for Git. Choose to log in with a web browser. It shows a one-time code. Note it, press Enter to open GitHub in your browser, enter the code there and authorize.

    Not sure what to pick? Ask the agent to walk you through it:

    Say this
    Walk me through signing in to the GitHub CLI with gh auth login, one question at a time.

  5. Check everything

    Say this
    Show me the versions of git, node and gh, and confirm gh is logged in.

Check it worked

The agent shows a version number for git, node and gh, and says gh is logged in to github.com as your-username.

Windows: “running scripts is disabled”

If you or the agent see an error that ends in running scripts is disabled on this system, go to Windows: allow scripts. It's a one-line fix. Then come back.

If the agent can't install them

Do this yourself

Download each missing tool, run its installer and keep the defaults. Then restart VS Code.

Mac

  • Git: open the terminal (View → Terminal), run xcode-select --install, and click Install in the window that appears.
  • Node.js: go to https://nodejs.org (opens in a new tab), download the version labeled LTS as the macOS Installer (.pkg), and run it.
  • GitHub CLI: install Homebrew by following https://brew.sh (opens in a new tab), then run brew install gh in the terminal.

Windows

  • Git: download Git for Windows from https://git-scm.com/install/windows (opens in a new tab). On the page about the initial branch name, choose Override the default branch name for new repositories and type main.
  • Node.js: go to https://nodejs.org (opens in a new tab), download the version labeled LTS as the Windows Installer (.msi), and run it.
  • GitHub CLI: download the installer from https://cli.github.com (opens in a new tab) and run it.

If it goes wrong

It says git, node or gh is "not recognized" or "not found", but I just installed it

VS Code is still using the old settings from before the install. Close every VS Code window and open it again. On Windows, if that doesn't help, restart the computer.

What the agent runs for you

The exact commands depend on your computer. They look like this:

# Windows
winget install --id Git.Git -e --source winget
winget install -e --id OpenJS.NodeJS.LTS
winget install --id GitHub.cli

# Mac
xcode-select --install
brew install node
brew install gh

# Both: new repos start on main
git config --global init.defaultBranch main

# The check
git --version
node -v
gh --version
gh auth status

Saved only in this browser.
