In the Claude app, Claude's cloud machine commits as Claude <noreply@anthropic.com> unless you say otherwise. Those commits aren't credited to you and don't show on your GitHub profile. One sentence fixes it.

Get your noreply email

It looks like ID+your-username@users.noreply.github.com. You copied it in Create your GitHub account. It's on GitHub under Settings → Emails. It credits you without putting your real email in your site's public history.

Tell the agent

  1. For this session

    For this repo, set git user.name to "Your Name" and user.email to "your-noreply-email", and commit as me from now on.

  2. Make it stick

    Each session starts on a fresh machine, so that setting is gone next time. Claude reads a CLAUDE.md file in your repo at the start of every session, so put the rule there:

    Add a CLAUDE.md file to this repo (or add to it if it exists) with this rule: Always commit as Your Name <your-noreply-email>. Then commit and push to main.

The agent commits with your computer's git identity. Set it once, and it applies to every repo on this computer:

Set my global git name to "Your Name" and email to "your-noreply-email".

The name is what your commits show, usually your full name. It doesn't have to match your GitHub username.

In a hurry? Add this to any prompt that commits: "Commit as Your Name <your-noreply-email>."

Claude may still add a Co-Authored-By: Claude line at the end of each commit message. That's a credit line. You're the author.

Anything you'd otherwise repeat every session belongs there. A short one looks like this:

# Rules for this repo
- Always commit as Your Name <your-noreply-email>.
- Only use facts you can cite with a link. Mark anything you can't verify as TBD.
Open https://github.com/your-username/your-repo/commits/main. Your newest commit shows your name and profile picture, not Claude's. Commits on main can take up to 24 hours to appear on your profile's contribution graph. Commits in a fork don't count there; see Clone, fork or copy.

If it goes wrong

My older commits still say Claude

The setting changes only new commits. Leave the old ones as they are.

My name shows on the commit, but not on my profile

Check three things: the email is your noreply address exactly, the repo isn't a fork, and the commit is on main. Then allow up to 24 hours.

What the agent runs for you 
# App path: this repo only (the machine is fresh each session)
git config user.name "Your Name"
git config user.email "your-noreply-email"

# VS Code path: every repo on your computer
git config --global user.name "Your Name"
git config --global user.email "your-noreply-email"

# Who wrote the last commit?
git log -1 --format="%an <%ae>"
