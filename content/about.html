Who made it

Jeremy Fritzhand, fritzhand on GitHub. He also made the starter sites the guide points to.

Why it exists

It's the shortest path from no GitHub account to a published website, made by telling an AI agent what you want. It teaches only what you need for that one goal. There are no servers, databases or frameworks here. You type or dictate, and the agent does the work.

How it's built

This site is itself a repo, fritzhand/quickstart, published with GitHub Pages from main and the /docs folder. It was made with Claude Code, by the same steps the guide teaches.

  • Each page is one HTML file in the content folder.
  • content/nav.json sets the sidebar and the page order.
  • node build.mjs turns them into the finished site in docs. It needs Node.js and nothing else.

Want a guide like this one about your own topic? Fork it:

Fork fritzhand/quickstart into my account and name the fork your-repo.

Then point it at your own address:

Work only in your-username/your-repo. Treat the other repos as read-only reference. In site.config.json, set siteName to "My Guide", siteBase to https://your-username.github.io/your-repo/, pathPrefix to /your-repo/ and repo to https://github.com/your-username/your-repo, and set the author to my name, Your Name, with https://github.com/your-username. Run node build.mjs until it finishes without errors, then commit and push to main.

Its CLAUDE.md explains the page format to the agent, and after each change the agent rebuilds the docs folder. Publish from main and /docs, as in Turn on GitHub Pages.
