Where to open it

  • Browser: go to https://claude.ai/code.
  • Phone or tablet: open the Claude app for iOS or Android and tap the Code tab.
  • Desktop app: open the Code tab in the Claude desktop app (https://claude.com/download) and choose Cloud instead of Local.

All three show the same sessions: start on your laptop, check in from your phone.

Set it up once

These steps are sign-ins and permissions on your own accounts, so only you can approve them.

  1. Sign in

    Use your Claude account on a paid plan: Pro, Max, Team or Enterprise. The free plan doesn't include Claude Code.

  2. Connect GitHub

    Claude asks you to connect GitHub and opens GitHub's authorization page. Approve it, and GitHub sends you back. On a Team or Enterprise plan, an admin may need to turn on GitHub access first.

  3. Install the Claude GitHub App

    Onboarding may offer it; if you skipped it, open https://github.com/apps/claude/installations/new. Choose your account, pick Only select repositories, select your repos and click Install. Claude can read public repos without it, but needs it to work in a private repo. Install it on every repo you want Claude to push to.

  4. Keep the Default environment

    Pro and Max get an environment named Default automatically. On Team or Enterprise, keep what's filled in on the form and click Create & finish.

Start your first session

  1. Pick a repository

    Use the repository selector below the message box. Leave its branch selector on the default, usually main. No repo yet? Open https://claude.ai/code?repositories=fritzhand/history-of-tampa to start with the Tampa starter selected. You'll make your own copy in Step 3.

  2. Choose a mode

    The mode menu next to the message box offers Auto (when available), Accept edits and Plan. Choose Plan to see the plan before anything changes.

  3. Ask something that changes nothing

    Type it, or dictate it with the microphone on your keyboard:

    Explain what this repo is and how its website is built, in plain English. Don't change anything.
Claude answers in plain English and changes no files. The session appears in the sidebar at claude.ai/code and in the Code tab of the Claude mobile app.

What happens when Claude works

  • It works on a copy. Claude clones your repo into a fresh cloud machine and works on a new branch named claude/…. When it reaches a stopping point, it pushes that branch to GitHub.
  • Each session starts fresh. Put standing rules in a CLAUDE.md file in your repo. Claude reads it at the start of every session.
  • It commits as Claude unless you say otherwise. Commit as yourself shows the rule to add.

You decide when the work reaches main, the branch your live site is built from. When you're happy, say:

Commit and push to main.

Or select Create PR at the top of the diff view and merge the pull request on GitHub. The main branch explains both.

If it goes wrong

My repo isn't in the list

A private repo appears only once the Claude GitHub App is installed on it, and a fork or new repo may need adding too. On GitHub, click your profile picture, then Settings → Applications → Installed GitHub Apps. Click Configure next to Claude, select the repo under Repository access, and click Save. Then start a new session and pick the repo.

Claude says it can't push

Install the Claude GitHub App on that repo (see above), then ask again. Claude also can't push to a repo that isn't yours, such as the original starter. Make your own copy first, in Clone, fork or copy.

What the agent runs for you

The cloud machine clones your repo, then Claude works on its own branch:

git clone https://github.com/your-username/your-repo.git
git switch -c claude/task-name
git add .
git commit -m "Describe the change"
git push -u origin claude/task-name

When you say "Commit and push to main", it moves the work onto main and pushes that instead:

git switch main
git merge claude/task-name
git push origin main
