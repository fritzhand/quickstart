Two trust questions

The first time you open a folder, you may be asked twice.

  1. VS Code asks first

    Do you trust the authors of the files in this folder?

    • Yes, I trust the authors: everything works.
    • No, I don't trust the authors: VS Code opens the folder in Restricted Mode. AI agents and the terminal are turned off, and the Claude Code extension doesn't work.

  2. Then the agent may ask

    The first time it works in a folder, the agent may ask its own version, such as whether you trust the files in this folder. The same rule applies.

Trust a folder only if you made it or cloned it from someone you trust. Open the project folder itself, or your Projects folder, never your whole Documents or home folder. Trusting a folder also trusts every folder inside it.

How the agent works in your folder

  • It reads the files in the folder to understand the project.
  • It proposes changes and edits files, then tells you what it did.
  • It runs commands, such as a build or a Git command. When it needs your OK, it shows a permission prompt. Read the command before you approve it. Pushes, deletes and installs deserve a careful look.
  • It commits and pushes when you tell it to.

How often it asks

You choose how often the agent stops to ask.

Click the mode at the bottom of the message box:

  • Manual: asks before it edits files or runs most commands.
  • Edit automatically: edits files without asking.
  • Auto: a background safety check reviews most actions instead of asking you. It's the default on Pro, Max and Team plans.
  • Plan: describes what it will do and waits for your OK before changing anything.

Use the permissions control below the message box. Ask for approval lets Codex work inside the folder and pauses before it reaches beyond it.

Undo and standing rules

  • Undo: ask the agent to "undo that last change." In Claude Code, you can also hover over a message, click the rewind button and choose Rewind code to here. Anything already pushed can be undone with Git: "Revert the last commit and push to main."
  • Standing rules: a CLAUDE.md file in the folder holds instructions the agent reads every time it starts, such as which name to commit as (see Commit as yourself). Codex reads a file called AGENTS.md instead.
There's no folder on your computer. The agent's folder is a fresh copy of the repos you picked, on a cloud machine.

If it goes wrong

I clicked No, and now the agent doesn't work

Open the Command Palette (Ctrl + Shift + P, or Cmd + Shift + P on Mac), run Workspaces: Manage Workspace Trust and trust the folder.

The agent asks about a folder I didn't expect

Say no. Then check that VS Code opened your project folder, not a folder above it. The folder's name shows at the top of the Explorer view. Use File → Open Folder… to open the right one.
