The app pathThe VS Code path
What it isClaude Code in the Claude appVS Code with the Claude Code extension or the Codex extension
Where the agent worksOn a fresh copy of your repo in the cloudIn a folder on your computer
What to installNothing in a browser. On a phone, the Claude app.VS Code, the extension, and a few free tools: Git, Node.js and the GitHub CLI. On Windows, one setting to allow scripts.
DevicesA phone or tablet, any web browser, or the Claude desktop appA Mac or Windows computer
CostA paid Claude plan: Pro, Max, Team or EnterpriseThe same for Claude Code. Codex needs ChatGPT Plus or higher.
Best forBeginners, phones, and the fastest startSeeing and opening your files on your computer, or using Codex

GitHub is free on both paths. The free Claude plan doesn't include Claude Code.

Which one?

  • New to this, or on a phone? Start with the app path. It's the fastest way to a live site.
  • Want to see the files on your computer? Pick the VS Code path. Codex users take this path too.
  • Can't decide? You don't have to. Both paths work on the same repo, because the real copy lives on GitHub. Push from one, then pull in the other.
