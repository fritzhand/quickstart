The easiest way to get a site you like is to show Claude one. Add your own repo, plus a repo to copy from: the Tampa starter, fritzhand/history-of-tampa, or this guide, fritzhand/quickstart.

  1. Pick your working repo

    Choose your own repo in the repository selector below the message box.

  2. Add the reference repos

    Add one or two more repos from the same selector. In the desktop app, click + next to the selected repository. Each repo shows its own branch selector; leave them on the default.

  3. Name the one to work in

    Claude puts all the repos side by side and starts in the folder above them, so it can't tell which one you mean. Always name it:

    Work only in your-username/your-repo. Treat the other repos as read-only reference. Look at how fritzhand/history-of-tampa builds its timeline and do the same in my repo.
Claude can read public repos, like both starters and this guide, without the Claude GitHub App. Your working repo needs the app if it's private. Claude Code in the app shows how to add it.
Ask "Which repo are you working in, and which files did you change?" Claude names your-username/your-repo, and every file it lists is in that repo.

If it goes wrong

Claude changed files in the wrong repo

Your starter on GitHub is safe: Claude can't push to a repo that isn't yours. Undo the stray edits and restate the rule:

Undo your changes in fritzhand/history-of-tampa. Work only in your-username/your-repo. Treat the other repos as read-only reference.
What the agent runs for you

The session clones each repo into its own folder, side by side. Claude moves into your repo before it edits or commits anything:

ls
# history-of-tampa  quickstart  your-repo
cd your-repo
